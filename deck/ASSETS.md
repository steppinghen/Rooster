# Assets

Every third-party or original asset in the app, with its source and license. Nothing is hotlinked; everything ships from our own origin.

## Fonts (self-hosted through npm `@fontsource/*`, bundled by Vite)

| Font | Use | Package | License | Author |
|---|---|---|---|---|
| Archivo Black | Display headings, stickers, buttons | `@fontsource/archivo-black` 5.3.0 | SIL OFL 1.1 | The Archivo Black Project Authors (Omnibus-Type) |
| Archivo (400, 600, 700, 800) | UI text, labels a kid must read | `@fontsource/archivo` 5.3.0 | SIL OFL 1.1 | The Archivo Project Authors (Omnibus-Type) |
| Permanent Marker | Small decorative labels, normal volume only | `@fontsource/permanent-marker` 5.3.0 | Apache 2.0 | Font Diner |
| Lexend (400, 600) | Reading activities | `@fontsource/lexend` 5.3.0 | SIL OFL 1.1 | The Lexend Project Authors |

The license texts ship inside each package (`node_modules/@fontsource/<name>/LICENSE`). OFL and Apache 2.0 both allow bundling in an app.
