# Parent screens

Part of The Deck brief. Rules in `CLAUDE.md` apply here too.

## Family features (for the parents, not just the kids)

The hub is for the whole household. Parent-facing features share the same backend, permissions, and look, with a cleaner, adult layout on the phone.

- **Shared calendar:** both parents add and edit events; day, week, and month views; per-event visibility (parents only, or also shown to kids as a countdown). Optional two-way sync with the family's Google Calendar later.
- **Menus and meal planning:** Snack Shack, a rolling dinner plan both parents can edit (see Parent Today and Snack Shack). Kids see tonight's dinner on The Point. Each meal can hold a recipe link and ingredients.
- **Shared lists:** groceries (ingredients from the menu can be added in one tap), errands, packing lists for trips.
- **Chores overview:** assign chores, set points and savings goals, approve completions (either parent).
- **Household notes:** a small shared board for things like babysitter info or reminders (no sensitive data such as passwords or ID numbers).
- **Parent home view:** Parent Today on the phone and the kitchen hub on the iPad (see Parent Today and Snack Shack).

## Calendar (Phase 1.5)

Reference frames: Parent screens page, row "Calendar — synced from Apple and Google".

- **Source of truth:** events are made and changed in Apple Calendar or Google Calendar. The Deck subscribes to whole calendars through read-only feed links fetched by the server (see Security), so nothing is cherry-picked or missed; the footer says "Synced N min ago". Starting calendars: Family (Apple, shared by both parents), Grandma's (Apple; her public link has to be turned on by her), Steve's work (Google secret address; skipped or free/busy only if the employer disables it) and Holidays (built in, drives the accents). Repeating events expand on the server; a stale feed shows a quiet "last updated" note.
- **Who sees what:** Family events show to kids by default with a per-event "Hide from kids"; Grandma's are hidden from kids with a per-event "Show to kids"; work never reaches kids' iPads. A hidden event shows as a dashed "Private" block on shared displays until a parent unlocks; work shows as "Busy" there by default (the display's mode per calendar decides). Plain events render as a dot in their calendar's color plus the calendar's name (never color alone); only events with a kid layer get stickers and countdowns. Kids see a plain event's raw title unless the kid layer gives it a kid title.
- **Phone Calendar tab:** month grid with today ringed and up to three calendar dots per day, a day list (time, title, calendar, "On Tour Dates" sticker tag, "Hidden from kids" tag) and a Calendars sheet with each parent's own toggles. No "+": add in Apple or Google.
- **Kitchen Calendar:** "This week" (rolling seven days from today, a weather tile per day from the forecast with the Open-Meteo credit, event cards with time, sticker and calendar) and "Month" (full grid, two events per day then "+N more", a small weather icon on forecast days). Calendar chips that anyone there can toggle among the calendars the display allows; tap a day for its list, tap an event for a side panel. Locked, anyone can look and the switches read "Unlock to change"; unlocked, Hide from kids or Show to kids work in place.
- **Manage calendars** (from the Calendars sheet or Back Office): each calendar with color, source, last sync and its kid default; tap one to edit its name, color (six named colors) and "Kids see its events" (Shown, Hidden, Never; Holidays always reach kids), see its sync count, or remove it. **Add a calendar:** pick Apple or Google for step-by-step help getting the link (Apple: Calendar app, Calendars, the info button, Public Calendar, Share Link; Google: Settings, the calendar, Integrate calendar, "Secret address in iCal format"), paste it, then name, color and kid default. The link is kept on the server only.
- **Later:** a read-only feed out of The Deck for Apple Calendar; kids requesting events (a friend's birthday) with parent approval, like chores (Phase 2).
